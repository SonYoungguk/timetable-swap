# 학교 시간표

한 학교가 쓰는 통합 시간표 웹앱. 시간표 편성 → 공개 → 수업 교체·실시간 공유 → 고교학점제·교과교실제 관리를 한 자료 구조 위에 차례로 얹는다.

## 되는 것

**편성 (담당자)**
- **기초 자료**: 학교 설정(요일별 교시 수, 점심, 교사 권장 시수), 교사(수업 불가 시간, 전용 교실), 과목(필요한 교실 종류), 교실(종류, 수용 인원), 학급. 엑셀에서 복사해 여러 줄 붙여넣기 가능.
- **수업 배정**: 학급·과목·교사·교실·주당 시수·연강. 합반과 선택과목 묶음(같은 시간에 여러 강좌가 열리는 수업) 지원.
- **시간표 편성**: 자동 편성(전부 다시 / 빈 수업만 채우기), 끌어다 놓기 수동 조정, 맞바꾸기, 고정(📌), 실행 취소, 충돌·권장 사항 검사.

**공개**
- **게시**: 편성 중인 안과 공개된 시간표를 분리한다. 위쪽 `게시` 버튼을 눌러야 조회 화면이 바뀐다.
- **조회·인쇄**: 로그인 없이 학급·교사·교실·학생별 주간 시간표와 전체 표를 본다. 휴대폰 화면 지원. 로그인하지 않은 사람에게는 편성 중인 안, 학생 이름, 교사 수업 불가 시간을 내보내지 않는다.

**수업 교체**
- 게시된 시간표를 기준으로 날짜별 맞교환·이동·대강·결강을 처리한다.
- 수업을 누르면 겹치지 않고 맞바꿀 수 있는 수업과 그 시간에 비는 교사를 추천한다.
- 변경은 열려 있는 모든 조회 화면에 바로 반영되고 알림이 뜬다. 변경 내역에서 되돌릴 수 있다.

**고교학점제**
- 학급별 학생 명단, 선택과목 묶음마다 학생이 듣는 강좌 지정.
- 강좌별 수강 인원과 명단, 학생 개인 시간표(조회 화면 → 학생).

**교과교실제**
- 교사 전용 교실 일괄 적용, 과목에 필요한 종류의 빈 교실 자동 배정.
- 교실별 가동률, 교실 종류 불일치·수용 인원 초과 점검, 교실 전체 시간표.

## 아직 없는 것

- 교사별 계정 (지금은 관리자 비밀번호 하나). 교사가 직접 교체를 신청·승인하는 흐름.
- 학생 수강 신청 자료로 선택과목 묶음을 자동 구성하는 기능 (묶음은 수업 배정에서 직접 만든다).
- 주를 넘기는 수업 이동 (교체는 같은 주 안에서만).
- 화면 밖 알림 (문자·메신저·푸시).

## 실행

Node.js 22.13 이상이 필요하다.

```bash
npm install
npm run build
ADMIN_PASSWORD=원하는비밀번호 npm start
```

브라우저에서 http://localhost:8787 을 열고 오른쪽 위 **편성 담당자 로그인**. 처음이라면 기초 자료 → 학교 설정 → **예시 학교 불러오기**.

- `ADMIN_PASSWORD` 를 정하지 않으면 시작할 때마다 임시 비밀번호를 만들어 터미널에 보여 준다.
- 자료는 `data/timetable.db` (SQLite) 한 파일에 저장된다. 이 파일을 복사하면 백업이다. 위치는 `DB_PATH`, 포트는 `PORT` 로 바꾼다.
- 개발할 때는 `npm run dev` (화면 http://localhost:5173), 자동 편성·교실 배정 검증은 `npm test`.

## 구조

| 위치 | 내용 |
| --- | --- |
| `shared/types.ts` | 자료 구조 (교사·과목·교실·학급·수업·배치) |
| `shared/model.ts` | 충돌 검사, 권장 사항 검사 |
| `shared/solver.ts` | 자동 편성 (탐욕 초안 + 담금질, 켐페 사슬 교환) |
| `shared/week.ts` | 날짜별 주간 시간표, 교체·대강 후보 계산 |
| `shared/rooms.ts` | 교실 자동 배정, 가동률, 점검 |
| `server/index.ts` | 저장, 로그인, 실시간 전파 |
| `src/` | 화면 (React) |
